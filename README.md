# Plane Tracker Monitor UI

An airport-style flight monitor display built with React Native and Expo, designed to show tracked flights in a visually appealing format similar to airport arrivals and departures boards.

![Flight Monitor UI](https://github.com/user-attachments/assets/95d428b5-e6a8-4115-87cb-34446b1100d9)

## Features

- 📱 **Mobile-First Design**: Optimized for phones and tablets with responsive layouts
- ✈️ **Airport-Style Display**: Classic arrivals/departures board aesthetic with customizable colors
- 🎨 **Multiple Themes**: Purple (default), Light, and Dark themes with easy customization
- 🔄 **Real-Time Updates**: Simulated real-time flight status updates (mock data for now)
- 🎭 **Smooth Animations**: Fade-in animations for flight rows (can be disabled)
- 🔀 **Dual View Modes**: Switch between Arrivals and Departures with a tap
- 📊 **Comprehensive Data**: Display time, airline, flight number, origin/destination, status, altitude, and speed
- ⚙️ **Configurable**: Easy-to-customize update intervals, animations, and display options

## Getting Started

### Prerequisites

- Node.js (v14 or higher)
- npm or yarn
- Expo CLI (optional, but recommended)

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/jromie0924/plane-tracker-monitor-ui.git
   cd plane-tracker-monitor-ui
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm start
   ```

### Running on Different Platforms

```bash
# Run on web
npm run web

# Run on Android (requires Android Studio / emulator or physical device)
npm run android

# Run on iOS (requires macOS with Xcode)
npm run ios
```

## Configuration

### App Settings

Edit `src/config/appConfig.ts` to customize:

```typescript
export const defaultConfig = {
  updateInterval: 30000,          // Update frequency (ms)
  defaultViewMode: 'arrivals',    // 'arrivals' or 'departures'
  animationsEnabled: true,        // Enable/disable animations
  soundAlertsEnabled: false,      // Sound alerts (not yet implemented)
  maxFlightsDisplayed: 20,        // Number of flights to show
  autoRefresh: true,              // Auto-refresh flight data
};
```

### Themes

Three built-in themes are available:
- **Purple** (Default): Classic airport monitor purple/magenta theme
- **Light**: Light mode with purple accents
- **Dark**: Dark mode with purple accents

To add a custom theme, edit `src/theme/themes.ts`:

```typescript
export const customTheme: Theme = {
  primary: '#YOUR_PRIMARY_COLOR',
  secondary: '#YOUR_SECONDARY_COLOR',
  background: '#YOUR_BACKGROUND_COLOR',
  // ... other colors
};
```

## Data Integration

### Current Implementation

The app currently uses **mock data** generated by `FlightDataService`. This simulates real-time flight updates with random status changes.

### Future Integration Options

#### 1. WebSocket Integration

For real-time updates with minimal latency:

```typescript
// src/services/WebSocketService.ts
const ws = new WebSocket('wss://your-flight-data-endpoint');

ws.onmessage = (event) => {
  const flightData = JSON.parse(event.data);
  updateFlights(flightData);
};
```

#### 2. AWS Pub/Sub (SNS + SQS)

For scalable, cost-effective solution:
- **Cost**: ~$0.36/month for 2 million messages
- Nearly free for modest usage (<1M messages/month)
- Set up SNS topic for flight updates
- Subscribe SQS queues for each monitor
- Poll SQS from the app

#### 3. AWS IoT Core (MQTT)

For true real-time push notifications:
- Use MQTT protocol for instant updates
- Highly scalable
- Built-in security with AWS IoT

#### 4. REST API Polling

Simple polling approach:

```typescript
setInterval(async () => {
  const response = await fetch('https://api.example.com/flights');
  const flights = await response.json();
  setFlights(flights);
}, 30000);
```

### Integration with plane-tracker-rgb-pi

This UI is designed to work with the [plane-tracker-rgb-pi](https://github.com/jromie0924/plane-tracker-rgb-pi) project. Flight data can be pushed from the RGB Pi tracker to this monitor UI via:

1. Direct REST API
2. WebSocket server
3. Cloud pub/sub (AWS SNS/SQS, AWS IoT Core)
4. MQTT broker

## Flight Data Schema

```typescript
interface Flight {
  id: string;
  flightNumber: string;      // e.g., "AA 1234"
  airline: string;           // e.g., "American Airlines"
  airlineCode: string;       // e.g., "AA"
  origin: string;            // Airport code, e.g., "JFK"
  destination: string;       // Airport code, e.g., "LAX"
  scheduledTime: string;     // ISO 8601 timestamp
  estimatedTime: string;     // ISO 8601 timestamp
  status: FlightStatus;      // Enum: Scheduled, Boarding, etc.
  altitude?: number;         // In feet
  speed?: number;            // In knots
  aircraft?: string;         // Aircraft type, e.g., "B737"
  gate?: string;             // Gate number, e.g., "A12"
}
```

## Customization

### Adding New Columns

Edit `FlightRow.tsx` and `FlightBoardHeader.tsx` to add new columns:

```tsx
// In FlightRow.tsx
<View style={styles.columnNewField}>
  <Text style={[styles.text, { color: theme.text }]}>
    {flight.newField}
  </Text>
</View>

// In FlightBoardHeader.tsx
<View style={styles.columnNewField}>
  <Text style={[styles.headerText, { color: theme.text }]}>
    New Field
  </Text>
</View>
```

### Modifying Update Behavior

Edit `FlightDataService.ts` to change how flights update:

```typescript
updateFlight(flight: Flight): Flight {
  // Custom update logic here
  return updatedFlight;
}
```

## Performance Optimization

- **FlatList Optimization**: Uses `removeClippedSubviews`, `maxToRenderPerBatch`, and `windowSize` for smooth scrolling
- **Native Animations**: Uses `useNativeDriver: true` for 60fps animations
- **Memoization**: Consider adding `React.memo` to components if performance issues arise
- **Lazy Loading**: Only renders visible rows with FlatList virtualization
